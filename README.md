# INOMNIOS
### Operations Intelligence · Interactive Concept Prototype

INOMNIOS is a proposed enterprise operations and ERP data-bridge concept. This repository currently contains a browser-based front-end demonstration.

## Open the prototype
After GitHub Pages deployment completes, visit:
**https://xiluqt.github.io/Inomnios/**

## Demonstration areas
- Operations overview dashboard
- Animated purchase-to-pay workflow simulation
- Finance, procurement, inventory, and people/access screens
- ERP data-bridge concept and connector catalogue
- Analytics and sample operational indicators

## Important scope disclosure
This is a front-end concept prototype. Figures and records are illustrative. Interactions are simulated locally. There is no production backend, authentication, database, or live ERP/API connection. The prototype must not be presented as a deployed ERP system.

## Deployment
A GitHub Actions workflow deploys the root website to GitHub Pages whenever changes are pushed to `main`.
